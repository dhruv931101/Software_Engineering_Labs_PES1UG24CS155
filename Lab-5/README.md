## Objective
To perform static code analysis on a Python Address Book application using Pylint, Bandit, and Flake8, identify code-quality and security issues, and improve the code based on the findings.

## Tools Used
- **Pylint:** Checks code quality, conventions, and potential errors.
- **Bandit:** Identifies potential security vulnerabilities in Python code.
- **Flake8:** Checks Python style and formatting issues.

## Files Included

| File | Description |
|---|---|
| `address_book.py` | Updated Address Book application after fixing identified issues. |
| `issue_table.md` | Summary of identified issues and their corresponding fixes. |
| `pylint_report_before.txt` | Pylint results before the fixes. |
| `pylint_report_after.txt` | Pylint results after the fixes. |
| `bandit_report_before.txt` | Bandit security findings before the fixes. |
| `bandit_report_after.txt` | Bandit security findings after the fixes. |
| `flake8_report_before.txt` | Flake8 findings before the fixes. |
| `flake8_report_after.txt` | Flake8 results after the fixes. |

## Results

- **Pylint:** Improved the code-quality score from 5.47/10 to 10.00/10.
- **Bandit:** No security issues identified in the final scan.
- **Flake8:** No style violations reported in the final scan.

## Conclusion
The Address Book application was improved by addressing code-quality, security, and formatting issues identified through static analysis. Before-and-after reports are included to document the results.
